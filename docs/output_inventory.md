# Output Inventory — daf-okn

> Every file in `output/` is **disposable but regeneratable**. This document
> is the contract between the workflow and the manuscript: it inventories
> what the workflow produces, which generator emits it, and which stage it
> lands in. It lives under `docs/` rather than project `output/` because it is
> source documentation for the producer/consumer graph that future agents and
> forkers need.

## Manuscript Token Contract

Every `{{TOKEN}}` used in `manuscript/*.md` must be declared in the
`variables:` block of `manuscript/config.yaml` and produced by
`src/daf_okn/core/manuscript_variables.py::generate_variables()`:

- `CONFIG_TITLE`, `CONFIG_SUBTITLE`, `CONFIG_VERSION`, `CONFIG_FIRST_AUTHOR`,
  `CONFIG_KEYWORDS` — from `manuscript/config.yaml`
- `GRAPH_NAME`, `NODE_COUNT`, `EDGE_COUNT`, `DENSITY_PCT`,
  `WEAKLY_CONNECTED_COMPONENTS`, `STRONGLY_CONNECTED_COMPONENTS`,
  `MEAN_DEGREE`, `TRIANGLE_COUNT`, `TOP_NODE_LABEL`, `TOP_NODE_CENTRALITY` —
  from `output/data/graph_report.json`
- `CONFIG_HASH`, `GENERATION_TIMESTAMP`, `PYTHON_VERSION`, `PLATFORM`,
  `NETWORKX_VERSION`, `MATPLOTLIB_VERSION` — computed at generation time

The regression test
`tests/core/test_manuscript_variables.py::test_all_manuscript_tokens_are_generated`
fails CI on any token used in prose that the generator does not emit. In
pipeline mode a missing `graph_report.json` fails the build; draft mode
(`--allow-draft`) substitutes explicit `"N/A"` sentinels.

## Adding a New Output File

1. Add the generator in the appropriate module:
   - **Data** → `src/daf_okn/analysis/` or a dedicated `src/daf_okn/core/` helper
   - **Figures** → `src/daf_okn/figures/` (invoked from `scripts/10_research_workflow.py`)
   - **Reports/packages** → `src/daf_okn/core/contribute.py` (provenance, checklist)
2. Append a row to the table above naming the file, role, generator, and pipeline stage.
3. If the new artifact feeds the manuscript, add a `{{TOKEN}}` to `generate_variables()` and declare it in the `variables:` block of `manuscript/config.yaml`.
4. Re-run the producing script (`uv run python scripts/10_research_workflow.py`, or the stage's thin wrapper) and confirm the new file appears.

## Regeneration Sequence

If any artifact is corrupted or stale:

```bash
# 1. Clean (optional but recommended for full regenerations)
rm -rf output/

# 2. Run the research workflow (produces data/, figures/)
uv run python scripts/10_research_workflow.py --cognitive-repo <vault>

# 3. Build the dashboard (produces web/dashboard.html)
uv run python scripts/build_dashboard.py --graph output/data/cognitive_kg.json

# 4. Hydrate manuscript variables (produces output/data/manuscript_variables.json)
uv run python scripts/z_generate_manuscript_variables.py

# 5. Package the contribution and record provenance (produces provenance/)
uv run python scripts/09_provenance_record.py --graph output/data/cognitive_kg.json
```
